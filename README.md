# PropertiesAnywhere – Backend

Spring Boot backend for the PropertiesAnywhere property rental application.

The backend provides REST APIs for managing users and property listings and connects to PostgreSQL.

## Tech Stack

- Java
- Spring Boot
- Gradle
- PostgreSQL
- Spring Data JPA

## Current Features

- User APIs
- Property APIs
- City-based property search
- Property descriptions
- Property image URLs

## Status

🚧 Work in Progress

More APIs, authentication, image uploads, and other features are planned.
